# WhyGraph 2.2.1

A small UI polish release for the portal. Nothing changes in the databases or the agent files, so
upgrading from 2.2.0 needs no steps and rolling back to 2.2.0 is safe.

## Fixes

- **Pointer cursor on clickable controls.** Buttons, tabs, switches, selects, menu items and the
  Chats `+` now show the hand cursor, except when disabled. Before, most of them showed the arrow.
- **Styled model suggestions.** The model field in Settings > Models and keys now opens a styled
  list, with the model id and its display name. An empty field, or one that already holds a listed
  id, shows the whole list. Typing filters by id or name, and any model id is still accepted.
- **Styled Provider and Effort selects.** The Provider select of each model row and the Chat row's
  Effort select now match the rest of the portal. Saved settings are unchanged, and a viewer sees
  both selects disabled.
