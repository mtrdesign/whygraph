# WhyGraph 2.8.0

Claude Code gets `/whygraph-claude-md`, which writes or revises a project's `CLAUDE.md` from the
repository, its history and your answers, with a source on every line. Nothing changes in the
databases.

!!! note "Upgrading and rolling back"
    From 2.7.1, run `whygraph update` (locally) or move the production image tag to `2.8.0`, then
    **Settings > Update agent files** in each project to get the new command. 2.8.0 changes no
    database, so to go back, re-run the installer from the `v2.7.1` tag and `whygraph up`
    (`whygraph update` refuses a downgrade).

## What's new

- **`/whygraph-claude-md` (Claude Code).** Drafts the project's root `CLAUDE.md`, and a
  directory-level `CLAUDE.md` only where a directory earns one, from the repository's scripts, CI
  commands and git history plus four short questions about what Claude keeps getting wrong. A line
  is kept only when it has a source and Claude could not find it by reading the repo. You see a draft
  and a ledger (**Kept**, **Moved**, **Dropped**, **Suggested, not written**, **Foreign blocks
  kept**) before anything is written, an existing file is backed up first, and every write goes
  through a checked tool that refuses any path but a `CLAUDE.md` inside the repository. It spends no
  LLM budget through WhyGraph: history is read with `describe: false` and rationale cards only when
  already cached. A decision tied to one symbol or file is proposed as a project note instead (at
  most five per run). Flags: `--no-interview`, `--no-nested`, `--no-notes`, `--write`. See
  [Writing CLAUDE.md](../portal/agents.md#whygraph-claude-md).
